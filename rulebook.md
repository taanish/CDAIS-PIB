# Classification Rules (Stage 3)

Every AI-keyword-matched release is classified into one of three types using the system test.

## The system test

> **[a specific government body]** is **[running / building / buying / testing]** **[a specific AI tool]**

If all three blanks fill, it's a **system**. If any blank won't fill, it isn't.

## The three types

- **System** — the system test passes. A specific government body is running, building, buying, or testing a specific AI tool.
- **Mention** — the release is about AI, but the system test fails. No specific tool, no specific government operator, or the AI is only discussed rather than being run/built/bought/tested.
- **Not AI** — the release isn't about artificial intelligence at all. The keyword match was a false hit.
